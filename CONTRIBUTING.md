# Работа с проектом

Исходники используют C++20. Физическое ядро не зависит от raylib и окна. Новые функции редактора и сохранений должны сохранять возможность чтения прежних сцен и отклонять некорректные данные без изменения текущей карты.

## Проверка изменений

```sh
cmake --preset core
cmake --build --preset core
ctest --preset core --output-on-failure
cmake --preset sanitize
cmake --build --preset sanitize
ctest --preset sanitize --output-on-failure
```

Для изменений интерфейса соберите preset `release` и запустите `--ui-test`, `--earth-test`, `--thermal-test`, `--workflow-test` через WSLg или X11. Не добавляйте в репозиторий сборки, личные карты, Toy Box или временный кэш таймлайна.

При сообщении об ошибке укажите шаги воспроизведения, версию компилятора, тип карты и приблизительное число частиц. Небольшую сцену для воспроизведения можно приложить к issue отдельно.
